# CyberCam

浏览器里的胶片相机。快门先把画面存成 16-bit 线性 RAW（`.filmraw`），再按所选机身的光学和胶卷显影。

取景已经套上风格，方便构图。RAW 文件本身不含暗角、裁切和胶卷颜色。同一张 RAW 可以换机身或胶卷重新显影。

## 开发

```bash
npm install
npm test
npm run dev
```

十卷胶片按扫描习惯分开：Portra 肤色暖但阴影不发雾，Gold 暖而天空还是蓝的，Superia 阴影偏青绿、高光带一点品红，800T 阴影偏青、亮处发暖。没有摄像头时可以导入一张照片，一样会先写 RAW 再显影。标题留在状态栏下面，相册和导入在快门两侧。取景画面上显示当前机身、胶卷、曝光补偿、ISO、快门、光圈和摄像头。ISO、快门和光圈是取景框下面的拨轮，手指左右滑动换挡，刻度跟着手指走；轮面是拉丝金属槽，当前档用象牙色定位楔标出来。ISO 跟着胶卷的标称感光度走；三者都会改变这张的曝光，ISO 高于胶卷时颗粒也会加重。手机上如果有多颗后置镜头，列表会分开显示；系统把它们藏在同一个后置摄像头后面时，应用会直接打开对应的那一颗。画面可以双指、滚轮或按钮在 1× 到 4× 之间缩放，快门按取景里看到的范围写入 RAW。竖屏时画幅跟着转成竖幅。成片保留摄像头给出的像素，长边最多 4096，JPEG 以较高质量保存。横屏不换布局，快门仍在取景框下面；手机横过来时，只有机身、胶卷、曝光、ISO、快门、光圈和变焦的文字跟着转正。回看时整张照片按原比例放进画面。换机身或胶卷时，选项马上换上，照片淡入新的显影，界面不会卡住。切到别的应用再回来时，取景会重新打开摄像头并继续刷新。

## Android release

工程在 `android/`，应用 ID 是 `app.cybercam.android`。签名配置在 `android/keystore.properties`，这把钥匙只用于当前仓库的 release 包。上架 Play Store 前请换成自己的钥匙。

```bash
npm install
npm run android:release
```

产物是 `android/app/build/outputs/apk/release/app-release.apk`。推送 `v*` 标签后，GitHub Actions 会用同一套签名打 APK 并发布到 Releases。手机上保存 RAW 或成片时，会打开系统分享。
